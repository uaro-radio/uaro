# Калькулятор втрат коаксіального кабелю

:::info[Інформація]
Цей калькулятор дозволяє розрахувати втрати потужності в коаксіальних кабелях та з'єднувачах 
на різних частотах. Ви можете додавати різні типи кабелів, з'єднувачів та атенюаторів, 
щоб змоделювати вашу реальну антенну систему.

Калькулятор містить характеристики популярних українських та зарубіжних кабелів.
:::

<Calculator />

:::warning[Примітки:]
- **Вузли системи:** Додавайте кабелі, з'єднувачі та атенюатори в порядку їх підключення.
- **Довжина кабелю:** Вказується в метрах з точністю до сантиметра (0.01 м).
- **Кількість з'єднувачів:** Вказується цілим числом (наприклад, 2 з'єднувачі).
- **Розрахунок втрат:** Використовується лінійна інтерполяція між відомими частотами.
- **Кольорове кодування результатів:**
  - 🟢 **Зелений:** Втрати менше 50% (прийнятно)
  - 🟡 **Жовтий:** Втрати 50-80% (потрібна увага)
  - 🔴 **Червоний:** Втрати більше 80% (критично)
- **Типи кабелів:**
  - **RG-58:** Тонкий кабель для КХ/УКХ (50 Ом)
  - **RG-8:** Товстий кабель для КХ (50 Ом)
  - **LMR-400:** Малошумний кабель для УКХ/НВЧ (50 Ом)
  - **RG-213:** Товстий кабель загального призначення (50 Ом)
  - **RG-174:** Дуже тонкий кабель для НВЧ (50 Ом)
  - **РК 50:** Радянські/українські кабелі (50 Ом)
  - **3D-FB:** Напівжорсткий кабель для НВЧ (50 Ом)
- **Провідники:**
  - **Моножила:** Кращі характеристики на високих частотах
  - **Багатожильний:** Більша гнучкість, гірші втрати на НВЧ
- **Частоти розрахунку:** 1.9, 3.75, 7.15, 14.15, 27.5, 52, 145, 435 МГц
- **Точність:** Результати є наближеними та залежать від якості кабелю та монтажу
- **Рекомендації:**
  - Використовуйте якомога коротші кабелі
  - Мінімізуйте кількість з'єднувачів
  - Для УКХ/НВЧ використовуйте кабелі типу LMR-400 або аналогічні
  - Перевіряйте КСВ системи після монтажу
:::
